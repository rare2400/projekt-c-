# ExpenseTracker
ExpenseTracker är en konsolapplikation där användaren kan hantera sina utgifter, genom att 
antingen lägg till i dem eller skapa en budget och planera sina utgifter. Applikationen är 
utvecklad med programmeringspråket **C#** och ramverket **.NET**. Den data man sparar placeras
i en JSON-fil. Man kan även ändra och ta bort data i applikationen, samt se alla sina sparade 
utgifter med en uträknat totalsumma.

## Verktyg
- C#
- .NET

## Struktur
- Models - Expense.cs
- Services - ExpenseTracker.cs
- Program.cs

## Använd applikationen
1. Klona repo
```bash
git clone https://github.com/rare2400/projekt-c-.git
```

2. Gå till ExpenseTracker-mappen
```bash
cd ExpenseTracker
```

3. Starta applikation
```bash
dotnet run
```
